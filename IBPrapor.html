Internet Tabanli Programlama Proje Raporu

Proje Adi: FEE CARS - Online Arac Galeri ve Yonetim Sistemi

Ders: Internet Tabanli Programlama

Rapor Amaci: Projenin sunucu/istemci mimarisi, kimlik dogrulama, ana islevler, AJAX entegrasyonu ve veritabani katmaninin ders gereksinimlerine gore dokumante edilmesi.

PHP JavaScript CSS AJAX (fetch API) DB: Oracle / PostgreSQL
Mimari: MVC benzeri katmanli yapi (Controller-Service-Repository)
API Yapisi: REST benzeri endpointler (/api/...)
Oturum: PHP session tabanli kimlik yonetimi
Rol Yonetimi: USER / ADMIN yetkilendirmesi

A) Projenin Tanimi ve Temel Sureci

Bu proje, kullanicilarin arac ilanlarini listeleyip filtreleyebildigi, detay goruntuleyebildigi, favoriye ekleyebildigi ve arac hakkinda talep/mesaj olusturabildigi bir web uygulamasidir. Admin kullanicilar ise arac ekleme-guncelleme-silme, talepleri yonetme, sohbetleri kontrol etme ve log kayitlarini goruntuleme islemlerini yapar.

Temel Is Akisi

  1. Kullanici giris/kayit ekranindan kimlik dogrulamasi yapar.
  2. Showroom ekraninda araclari listeler ve filtreler.
  3. Arac detayinda favori, talep ve sohbet islemleri yapar.
  4. Admin panelinde CRUD islemleri ile envanteri yonetir.
  5. Tum kritik oturum hareketleri aktiviteler tablosuna loglanir.

B) Modul 1 - Kullanici Kimlik Dogrulamasi

1. JS Dogrulamasi (Istemci Tarafi)

  • Giris/kayit formunda e-posta format kontrolu ve minimum sifre uzunlugu kontrolu yapilmaktadir.
  • Kayit modunda ad-soyad minimum karakter kontrolu uygulanmaktadir.
  • Admin arac ekleme/guncellemede zorunlu alanlar (marka, model, yil, fiyat, km) bos gecilemez.
// public/assets/js/app.js
const validationError = validateAccessForm(mode);
if (validationError) {
	toast(validationError);
	return;
}

2. PHP Dogrulamasi (Sunucu Tarafi)

  • AuthService icinde ad-soyad, e-posta ve sifre kontrolleri yapilir.
  • CarService icinde zorunlu alan kontrolu ve durum (AVAILABLE/SOLD) gecerliligi kontrol edilir.
  • InquiryService ve ChatService icinde mesaj uzunluk ve erisim kontrolleri vardir.
// app/services/AuthService.php
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
	throw new InvalidArgumentException('Gecerli bir e-posta giriniz.');
}

3. Sifre Guvenligi - SHA + Guvenli Hash

Proje gereksinimine uygun olarak sifreler once SHA-256 ile ozetlenmekte, sonra guvenli parola hash mekanizmasi ile veritabanina kaydedilmektedir. Giriste SHA-256 tabanli dogrulama yapilir; eski hash kayitlari geriye donuk uyumlulukla dogrulanip otomatik migrate edilir.

// app/services/AuthService.php
$shaPassword = hash('sha256', $password);
$hash = password_hash($shaPassword, PASSWORD_DEFAULT);

$verifiedWithSha = password_verify($shaPassword, $user['password_hash']);

4. Veritabani Sorgulama

Kullanici sorgulari UserRepository katmaninda parametrik SQL ile calisir:

// app/repositories/UserRepository.php
SELECT user_id, full_name, email, password_hash, role, is_active
FROM users
WHERE LOWER(email)=LOWER(:email)
FETCH FIRST 1 ROWS ONLY

C) Modul 2 - Ana Islev (CRUD + Is Kurallari)

1. PHP Islevleri

  • Arac listeleme/detay: /api/cars, /api/cars/{id}
  • Admin arac ekleme/guncelleme/satma/silme: /api/admin/cars (POST), /api/admin/cars/{id} (PUT/DELETE), /mark-sold
  • Favori islemleri: /api/favorites ve /api/favorites/{carId}
  • Talep olusturma ve admin durum guncelleme: /api/inquiries, /api/admin/inquiries/{id}

2. JS Islevleri ve Dogrulama

  • Filtreleme: marka/model/min-max fiyat parametreleriyle dinamik listeleme.
  • Form submitleri fetch API ile asenkron olarak backend endpointlerine gonderilir.
  • Hatali girislerde kullaniciya toast mesajlari ile geri bildirim verilir.

3. CSS (Sayfa Gorunumu)

  • Tek bir merkez stylesheet dosyasi ile tutarli tema kullanilmistir.
  • Auth, showroom, detay, admin ve modal bilesenleri responsive olarak tasarlanmistir.
  • Button, kart, form ve tablo bilesenlerinde ortak sinif yapisi tercih edilmistir.

4. SQL/DB Katmani

Veri yapisi users, cars, inquiries, favorites, chat_conversations, chat_messages, user_activity_logs gibi tablolarla iliskisel olarak kurgulanmistir.

TabloAmac
usersKullanici kimlik bilgileri, sifre hash, rol ve oturum alanlari
carsArac envanteri, teknik ozellikler, fiyat, durum
favoritesKullanici-favori iliskisi
inquiriesKullanici talepleri ve admin isleme durumlari
chat_conversations / chat_messagesKullanici-admin mesajlasma altyapisi
user_activity_logsLogin/logout/failed_login gibi hareket kayitlari

D) Modul 3 - AJAX Entegrasyonu

Proje genelinde AJAX ihtiyaci fetch API ile merkezi bir api() yardimci fonksiyonu uzerinden karsilanmistir. Sayfa yenilemeden veri cekme/gonderme yapilir.

// public/assets/js/app.js
const res = await fetch(`${candidates[i]}${path}`, cfg);
const data = await res.json().catch(() => ({}));

AJAX Kullanilan Baslica Senaryolar

  • Giris/kayit/logout islemleri
  • Arac listeleme, detay cekme ve filtreleme
  • Favori ekleme-cikarma
  • Talep olusturma ve durum guncelleme
  • Admin panelinde arac CRUD islemleri ve resim yukleme
  • Sohbet mesajlarini getirme/gonderme islemleri
